# Prompt 18 — Staff HR and payroll (Phase 2)

**Mode:** Plan, approve, implement after core identity/attendance/finance foundations are stable.

> Implement only the HR/payroll requirements confirmed by the school. Potential scope: staff employment history, departments/designations, leave requests/approvals, salary components, allowances/deductions, payroll periods, payslips, and salary disbursement records. Do not assume government/MPO workflows or statutory calculation rules without requirements and authoritative documentation.
>
> Payroll periods must be reproducible: preserve the salary components and rules used in each finalized run. Use decimal/integer-safe calculations, authorization-separated preparation/approval, auditable corrections, and transactions for payroll finalization. Restrict access to salary and employment data. Use fake external services.
>
> Include tests for calculation boundaries, finalized-run immutability, corrections, permissions, leave balances if implemented, and tenant isolation. Document every calculation and unresolved legal/accounting assumption. Do not implement until the core user/permission and staff modules exist.
